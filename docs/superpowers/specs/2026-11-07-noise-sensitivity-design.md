# Чувствительность к звуку

Запрос: усилить обнаружение тихих звуков и заменить ползунок списком из пяти вариантов.

Причина ограничения: минимальный RMS-порог `0.005` закреплён в интерфейсе, детекторе, API и проверке сохранённых комнат. Сигнал `0.002` никогда не проходит этот порог. Измерение RMS и отключение шумоподавления уже работают корректно.

## Подход

Выбран простой список порогов: `0.1` — «Только очень громкие», `0.03` — «Громкие», `0.01` — «Обычные», `0.003` — «Тихие», `0.0005` — «Даже очень тихие». Значения выбраны при реализации; минимальный порог в десять раз ниже прежнего. Новая комната начинает с `0.01`.

Альтернативы: усиление аудиосигнала меняет измеряемый уровень без необходимости; автоматическая калибровка добавляет отдельное поведение и не нужна для этого исправления.

Старые комнаты сохраняют точный порог до явного изменения чувствительности. Список показывает ближайший по отношению амплитуд вариант. Сохранение только интервала фото не меняет старую чувствительность. API принимает старые значения вплоть до `0.5`.

Порог применяется после «Сохранить настройки». Подсказка объясняет это. Остаются прежними защита от импульсов короче 150 мс, группировка событий, частота фото и измерение исходного сигнала.

Проверка: тихий синтетический сигнал создаёт событие только при достаточной чувствительности; выбор сохраняется после перезагрузки страницы и сервера. Проверка на настоящем микрофоне остаётся пользовательской.
