# Предварительная калибровка без видео

Пользователь уточнил: калибровка — предварительная настройка и должна работать без запуска видео/наблюдения. Прежняя зависимость от включённой камеры не соответствует этому сценарию.

Выбран самостоятельный краткий захват только микрофона. Альтернатива запуска полного наблюдения отвергнута: она требует камеру и очищает историю; постоянный предварительный захват не нужен для замера за 5 секунд.

- Кнопка доступна на странице устройства питомца до наблюдения. Она запрашивает только выбранный микрофон (`video: false`), показывает ожидание разрешения, затем уровень звука и 5-секундный прогресс.
- Отмена доступна и при ожидании разрешения. Завершение, отказ, скрытие вкладки, потеря микрофона, смена комнаты или закрытие монитора освобождают временные ресурсы. Если разрешение пришло после отмены, полученные дорожки немедленно закрываются.
- Предварительный замер не запускает камеру, медиатрансляцию, heartbeat или события и не меняет историю. Результат остаётся черновиком до «Сохранить настройки».
- При уже работающем наблюдении используется его микрофон без повторного запроса; существующие правила событий и интервалов сохраняются.
- Пока идёт запрос/замер, выбор устройств и запуск наблюдения заблокированы. Уже работающее наблюдение можно остановить. Внутренний startHost также отменяет предварительный замер, чтобы не оставлять параллельные захваты.

Реализация: отдельная временная сессия в createMonitor с текущими callbacks onCalibration/onLevel/onInputStatus; добавляется состояние starting. UI различает работу микрофона для настройки и наблюдение с видео. Алгоритм, API хранения и пороги остаются прежними.

Проверка: TDD тесты жизненного цикла и отсутствия сетевых/видео действий; браузерные сценарии запрета камеры, сохранения результата, отказа/отмены и позднего разрешения, прежняя калибровка во время наблюдения. Продолжение разрешённой пользователем публикации на Mac mini после проверок.
