# BarkOdd на Mac mini под /barkodd/

**Цель:** по прямому запросу пользователя развернуть приложение на `https://dog.example.com/barkodd/`.

**Решение:** существующий Caddy снимает префикс через `handle_path`; Go продолжает обслуживать внутренний корень. Web-клиент строит URL относительно каталога своего модуля, публичный URL сервера допускает безопасный путь для QR. Это небольшая адаптация существующего приложения. Переписывание JS прокси и перехват корневого `/api` затронули бы соседнее приложение, поэтому не используются. Новые домены и сертификаты не нужны.

**Ограничения:** без коммитов; отдельного Git-репозитория здесь нет. Существующие сервисы и данные не заменять. TURN за домашним NAT проверять отдельно; наличие URL не доказывает доступность relay.
