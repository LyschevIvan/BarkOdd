# README and Make Implementation Plan

**Goal:** Документировать BarkOdd и обеспечить воспроизводимые команды запуска.

**Architecture:** Make вызывает компактный Bash launcher; Go-приложение не меняется. Новая локальная Compose-конфигурация дополняет существующие варианты размещения.

**Tech Stack:** GNU Make 3.81, Bash 3.2, Go, Docker Compose, Markdown.

**Spec:** [Дизайн](../specs/2026-11-16-readme-make-design.md).

## Задачи

- [x] Добавить `Makefile`, `scripts/dev.sh`, локальный Compose и безопасный пример окружения. Проверить подготовку нового окружения, сохранение существующего, приоритет переменных и разделение данных.
- [x] Сохранить руководство в `docs/guide.md`, написать `docs/running.md`, оформить корневой README с быстрым стартом и таблицей команд. Исправить обнаруженные неточности о QR, PUBLIC_URL и восстановлении сессий.
- [x] Проверить сборку, Go race/vet, JS-тесты и запуск каждой конфигурации на временных данных. Проверить Compose config для local/public/macmini; запустить локальный контейнер при доступном Docker.
- [x] Независимо проверить изменения, исправить существенные замечания и сообщить фактические результаты.

## Риски для проверки

Существующий `.env` не должен затираться; shell-метасимволы в значениях не исполняются; localhost не наследует случайно production-подпуть; режимы с пользователями не открывают их данные в общем кабинете; остановка Docker не удаляет volumes. Проверки используют временные данные и не затрагивают существующие комнаты.

Работа выполняется в текущем чистом checkout `codex/auth-modes`. Коммиты и публикация не выполняются.

## Результаты проверки

- GNU Make 3.81 / Bash 3.2: help, синтаксис скриптов, dry-run и smoke-проверки launcher прошли.
- go test -race ./..., go vet ./... и 157 JS-тестов прошли; make build собрал бинарник.
- На временной копии проекта проверены все 6 сочетаний auth/transport: health, вход, API транспорта, сохранение комнат и кода, разделение данных, остановка через Ctrl+C без оставшегося процесса.
- Compose config --quiet прошёл для local/public/macmini. Локальный Docker-образ собран, контейнер healthy, HTTP healthz=200; контейнер остановлен с сохранением volume. Внешний HTTPS/Caddy не разворачивались.
- Независимый review не выявил оставшихся существенных замечаний. .env.* исключены также из Docker build context.
- Относительные ссылки документации и git diff --check прошли.
